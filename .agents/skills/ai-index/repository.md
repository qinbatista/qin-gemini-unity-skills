# Source and delivery

This repository owns the Google Antigravity / Gemini port of Qin's reusable Unity and C# skills, continuously templated from [`qin-unity-skills`](https://github.com/qinbatista/qin-unity-skills). The [root contract](../../../AGENTS.md) preserves installation, Codex isolation, Git, and publication boundaries.

Edit `skills/unity-lifecycle/` for Antigravity adapter logic and scripts; keep `skills/unity-*-skill/` cleanly mirrored via `sync_from_template.py`. [PORTING.md](../../../PORTING.md) documents the template-sync architecture and global Antigravity integration.
